# Demo Script

## 3-minute walkthrough

1. Open the app and click `Load Demo Student`.
2. Explain that the profile is preloaded for a third-year B.Sc. Computer Science student targeting a Data Analyst role.
3. Navigate to the Home Dashboard and show top role matches.
4. Open Skill Assessment to explain the skill snapshot and category view.
5. Go to Career Recommendations and emphasize how the match score is computed from weighted role requirements.
6. Open Skill Gap Analysis and highlight SQL, Statistics, Power BI, and Git as major gaps.
7. Show Free Learning Finder with resource cards and official links.
8. Click Generate / Regenerate Learning Plan and explain the weekly plan logic.
9. Open Progress Tracker and show completion tracking.
10. Download the CSV/PDF report and explain the sample output.

This entire flow demonstrates a complete student journey in under three minutes.
